# Building the Ramya Devi website with Astro

The Ramya Devi website is being designed as a technology and product platform covering software products, courses, documentation and technical articles.

Astro provides a lightweight foundation for building this public-facing website.

## Why Astro?

The website contains a significant amount of content that does not need client-side JavaScript.

Astro allows most of the site to be delivered as static HTML while still allowing interactive components where required.

## What comes next?

The website will gradually introduce:

- Digital products
- Technical courses
- Documentation
- Technical articles
- AI and data science projects
- Product information
